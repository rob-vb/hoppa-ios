# Hoppa — Context

Glossary of the Hoppa domain. All domain terms are English. This file holds terms only, no implementation details.

## Glossary

- **Logbook**: Everything Hoppa knows about one lifter: the Plate Inventory, every Program, the Open Workout if there is one, and every finished Workout. There is one Logbook, and it lives on the phone.
- **Program**: A training plan a user follows. Holds an ordered list of Workout Days, a Progression Mode (default for all its Exercises), and a default Weight Unit for new Exercises. A Program can hold Exercises in both units.
- **Workout Day**: A named template inside a Program (e.g. "Push", "Pull", "Legs"). Holds an ordered list of Exercises.
- **Workout**: One performance of a Workout Day in the gym. Logging happens against a Workout. A Workout is Open from the moment the user starts it until the user Finishes or Discards it. Only one Workout is Open at a time. A Workout keeps the date it started, even if the user finishes it on a later day. A Workout also keeps the Name of its Workout Day and of every Exercise performed. Hoppa shows the live Name while the Exercise exists, and falls back to the kept Name only after a delete.
- **Finish**: The action that ends a Workout and keeps every logged Set. Hoppa allows Finish only when no Exercise is Open. Hoppa never finishes a Workout by itself.
- **Discard**: The action that ends a Workout and keeps nothing.
- **Workout Summary**: The screen Hoppa shows after Finish. It leads with the Exercises whose Working Weight went up.
- **Exercise**: One movement inside a Workout Day. Holds: a Name, number of Sets, a Rep Range, a Working Weight, a Weight Unit, an Increment, a Microloading Increment, an Equipment Type, and optionally a Progression Mode override. It also holds a Base Weight for a Smith Machine or Plate-loaded Machine, a Stack Step for a Machine (stack) or Cable, and a Microload only where its Weight Unit differs from the Plate Inventory's. An Exercise holds both Increments at all times, whatever its Progression Mode, so switching the mode never asks for a value again.
- **Name**: The text that identifies an Exercise to the user. It is a label only: two Exercises with the same Name are still two Exercises, with their own Working Weight and their own progression. Free text; the user can rename an Exercise at any time without losing its logged Sets or its Working Weight.
- **Exercise Catalogue**: The fixed list of about 150 Exercise Names that Hoppa ships. It is a typing aid: picking an entry sets the Name and nothing else. Hoppa proposes the Names the user already created, above the Catalogue. In code it is `ExerciseCatalogue.names` in `HoppaRules`, beside the rule that ranks it against the user's own Names.
- **Weight Unit**: kg or lbs. Set per Exercise, so one Program can mix them: a kg plate rack and an lbs stack machine in the same gym. The Plate Inventory sets the unit, and the user cannot change it, for every Equipment Type that loads plates off the user's own rack: Barbell, Smith Machine, Plate-loaded Machine and Bodyweight. Dumbbell, Machine (stack) and Cable carry their own unit, which is the one the machine is marked with.
- **Set**: One performed group of reps of an Exercise. It holds the rep count achieved, the weight, the Weight Unit, the Microload and the One-off mark, as performed. A Set is a record of the past: no later edit to the Exercise, the Program or the Plate Inventory changes it. A Set does not hold a Plate Breakdown, because that is a solve and not a fact of the lift.
- **Performed Exercise**: One performance of an Exercise inside a Workout, as a Workout is one performance of a Workout Day. It holds the Exercise it performed, that Exercise's Name as it read at the time, its Exercise State, its logged Sets, a One-off Weight while one applies, and — once the user Finishes — its Progression Outcome.
- **Exercise State**: Every Exercise in a Workout is Open, Completed, or Skipped.
  - **Open**: The user has not settled this Exercise yet. Every Exercise starts Open. If the user navigates past an Open Exercise, it stays Open: that means "later", not "never".
  - **Completed**: The user settled this Exercise as performed, either by logging all planned Sets or by ending it early with fewer Sets. A Completed Exercise goes back to Open if the user raises the planned Sets above the number of Sets logged.
  - **Skipped**: The user decided not to perform this Exercise in this Workout. A Skipped Exercise logs no Sets, so it never progresses. The user can reopen a Skipped Exercise during the same Workout.
- **Rep Range**: The target span of reps per Set (e.g. 8–12). The bottom and top of the range drive progression.
- **Working Weight**: The current weight the user lifts for an Exercise, in the Exercise's Weight Unit. For Bodyweight exercises it is the added weight only. It changes through Progression, or through a deliberate change by the user. Hoppa never lowers it by itself. A Working Weight can be **unset**: a new Exercise has none until the user types one, and a change of Weight Unit clears it back to unset. Unset is not zero, because zero is a real weight — a Bodyweight Exercise done with no belt. An Exercise with no Working Weight does not progress.
- **Microload**: Added weight that hangs on the pin beside the Working Weight, in the Plate Inventory's unit. It exists only on a Machine (stack) or a Cable whose Weight Unit differs from the Plate Inventory's unit, because the two units never convert: an lbs stack machine with a kg microplate on the pin reads `100 lbs + 1 kg`, and Hoppa shows no total. Those are the only two Equipment Types with a pin to hang it on and a Stack Step to roll it into. Where the units match there is no Microload, and Microloading moves the Working Weight instead. A Microload is a weight, never a count of plates, and it is always smaller than one Stack Step.
- **Roll-up**: What keeps a Microload small. When a progression would take the Microload to one Stack Step or more, Hoppa adds one Stack Step to the Working Weight instead and keeps the remainder as the new Microload, rounded up to a weight the Plate Inventory can build. So the pin climbs and the hook never carries more than one pin step of iron. Rounding up is what keeps the weight from ever going down. Hoppa compares the two units to do this, but only inside itself: no converted number ever reaches the screen.
- **One-off Weight**: A weight the user uses for one Workout only. Hoppa logs its Sets, but it never becomes the Working Weight and it never progresses.
- **Target Reps**: The pre-filled rep count for a Set during logging: the top of the Rep Range.
- **Increment**: The weight added on progression in Progressive Overload mode. Per Exercise, in the Exercise's Weight Unit, any value the user types. Defaults: 2.5 kg, 5 kg for leg exercises (lbs: 5 / 10).
- **Progression Mode**: Either Progressive Overload or Microloading. Set on the Program; an Exercise may override it.
- **Progressive Overload**: If the user reaches the top of the Rep Range in all Sets of an Exercise, the Working Weight goes up by the Increment next time. Otherwise it stays the same.
- **Microloading**: If the user reaches the bottom of the Rep Range in all Sets of an Exercise, the weight goes up by the Microloading Increment next time. Otherwise it stays the same. The weight that moves is the Working Weight, or the Microload on a stack or cable whose unit differs from the Plate Inventory's — and a Microload that reaches one Stack Step becomes a pin step; see Roll-up. A Barbell, Smith Machine and Plate-loaded Machine take one Microplate per side, so the weight goes up by twice the Microplate. Every other Equipment Type takes one Microplate, so the weight goes up by exactly the Microplate. Microloading is available on every Equipment Type, with one refusal: a Dumbbell whose Weight Unit differs from the Plate Inventory's has no pin and no Stack Step, so it has nowhere to put the plate, and Hoppa says so on the Exercise sheet.
- **Progression**: Hoppa evaluates progression per Exercise, never per Workout. An Exercise progresses only when the user logs at least the planned Sets and every Set meets the threshold of its Progression Mode. Hoppa reads the planned Sets and the Rep Range as they stand at Finish, so a change during the Workout counts for that Workout. An Exercise with fewer Sets logged than planned keeps its Working Weight: it does not go up, and Hoppa never lowers it. So a Workout the user stops early still progresses the Exercises the user completed in full. Hoppa applies the new Working Weight at Finish; the user accepts nothing.
- **Progression Outcome**: What progression did to one Performed Exercise, written at Finish and never worked out again: the planned Sets and the threshold that applied, and whether the Working Weight went up. History reads it as a fact, so a later edit to the Rep Range or the planned Sets cannot rewrite a past Workout.
- **Microloading Increment**: The Microplate Hoppa adds on progression in Microloading mode. Per Exercise, chosen from the Microplates in the Plate Inventory, so it always names a plate the user owns. It keeps the Plate Inventory's unit, even when the Exercise uses the other unit. A Plate Inventory that holds no Microplate can name none, so an Exercise on Microloading has no Increment until the user switches a Microplate on. The user can change it at any time; the next progression uses the new Microplate and nothing else happens. Where Hoppa fills one in by itself, it fills in the smallest Microplate switched on, because the smallest jump the rack can make is the point of Microloading.
- **Microplate**: A small plate (e.g. 0.25 kg) used for Microloading. Goes on the bar, or hangs on the pin of a stack or cable machine.
- **Stranded Exercise**: An Exercise on Microloading whose Microloading Increment names a Microplate the user has switched off. It does not progress, and Hoppa says so where the user stands. Hoppa never picks another plate for it, and it stores nothing: switch the Microplate back on and the Exercise progresses again with the plate the user chose.
- **Re-weigh list**: One screen holding every Exercise that has no Working Weight, each with an empty weight field. It appears after the user changes the unit of the Plate Inventory, which clears the weight of every Exercise that reads its unit from the rack. The list is not written down anywhere: it is the Exercises without a weight, so it survives leaving the screen and closing the app.
- **Deload**: A deliberate weight reduction. Hoppa never deloads automatically.
- **Equipment Type**: How an Exercise is loaded. The four types loaded from the user's own rack take their Weight Unit from the Plate Inventory. The other three carry their own. One of:
  - **Barbell**: 20 kg bar (45 lbs), plates per side. Plate Breakdown applies.
  - **Smith Machine**: Base Weight set per Exercise, plates per side. Plate Breakdown applies.
  - **Plate-loaded Machine**: A machine loaded with plates (e.g. leg press). Base Weight set per Exercise, plates per side. Plate Breakdown applies.
  - **Dumbbell**: Shows the weight per dumbbell only.
  - **Machine (stack)**: Shows the pin weight plus Microplates.
  - **Cable**: Same display as Machine (stack).
  - **Bodyweight**: Shows added weight only (e.g. weighted chin-ups). Progression applies to the added weight. The added weight is a plate off the user's own rack, hanging from a belt, so the Plate Inventory sets the unit here too.
- **Base Weight**: The empty-carriage weight of a Smith Machine or Plate-loaded Machine. Differs per gym; the user sets it on the Exercise.
- **Stack Step**: The fixed jump of a weight stack on a Machine (stack) or a Cable, for example 10 lbs. Differs per machine; the user sets it on the Exercise. The pin sits at the largest Stack Step at or under the Working Weight, and the remainder hangs on the pin as Microplates. It is also the ceiling of a Microload: see Roll-up.
- **Plate Breakdown**: The per-side list of plates the user must load to reach the Working Weight. Hoppa solves it from the biggest plate down. The Progression Mode decides which plates it may use: Progressive Overload uses the normal plates only, and Microloading uses the Microplates as well. So the same weight can draw two different loads on the same bar, depending on the Exercise's mode.
- **Plate Inventory**: The plate sizes available in the user's gym, in one unit. Hoppa holds one Plate Inventory. That unit sets the Weight Unit of every Exercise with a Plate Breakdown. It holds the normal plates and the Microplates as two groups, each size on or off, with no count of pairs. Defaults (per side, kg): 1.25, 2.5, 5, 10, 20 on; 25 off; Microplates 0.25, 0.5, 0.75, 1 all off. Defaults (lbs): 2.5, 5, 10, 25, 45 on; 35, 55 off; Microplates 0.5, 1, 1.25, 2.5 all off. Every Microplate ships off because most gyms own none, so a Plate Inventory holds no Microplate until the user says otherwise.
- **Rest Timer**: A count-up stopwatch that starts automatically after each logged Set.
